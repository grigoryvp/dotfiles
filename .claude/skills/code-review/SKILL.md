---
name: code-review
description: Review current branch changes
---

Проведи ревью изменений в текущей ветке.
Найденные недостатки отсортируй по важности.
Напиши общее количество найденных недостатков, которые нужно исправить
до merge.
Если такие недостатки есть, то покажи не больше трех, начиная от самого
важного, в виде нумерованного списка на русском языке.
Для каждого недостатка кратко сформулируй в чем он заключается и в какой
ситуации проявляется.
Если ты видишь для недостатка очевидные решения, то кратко перечисли их после
описания недостатка.
