Проведи ревью изменений в текущей ветке относительно дефолтной ветки.
Читай не только diff, но и окружающий код, чтобы понимать контекст изменений.

Для каждого замечания укажи:
- severity: `blocker` (ломает поведение или данные), `major` (нужно исправить
  до merge), `minor` (желательно, но merge не блокирует);
- file и line (строка в версии из текущей ветки);
- title: в чём заключается недостаток, одно предложение;
- situation: в какой ситуации проявляется, одно-два предложения;
- fixes: очевидные решения, если видишь их, кратко.

Отвечай по-русски. Финальный ответ — только JSON по схеме ниже, без
дополнительной прозы:

```json
{
  "findings": [
    {
      "severity": "blocker | major | minor",
      "file": "path/relative/to/repo",
      "line": 123,
      "title": "...",
      "situation": "...",
      "fixes": ["...", "..."]
    }
  ]
}
```

Если замечаний нет, верни `{"findings": []}`.
