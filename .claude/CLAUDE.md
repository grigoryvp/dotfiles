Если задача сформулирована по-русски, то отвечай тоже по русски.

Если в задаче явно не сказано делать коммиты и/или MR, то только редактируй
код.

Комментарии в коде всегда пиши по-английски. После завершения работы над кодом
проверь, что: добавленные и измененные комментарии действительно нужны и
рассказывают историю, которую не видно из кода, а не повторяют код;
добавленные и измененные комментарии лаконичны, только необходимый минимум,
без излишних подробностей.

Словом "мы" обозначаются совместные с агентом действия, например "наш код".

После работы с Python кодом примени ruff и mypy к тем частям кода,
которые были написаны или изменены тобой.

Для доступа к GitLab используй утилиту `glab`

Если задача написать shell код, используй синтаксис portable shell.
