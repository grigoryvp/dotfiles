Проведи ревью изменений в текущей ветке двумя независимыми ревьюерами
параллельно, затем объедини их замечания.

Промпт ревью: `~/dotfiles/prompts/code-review.md`.
JSON-схема замечаний: `~/dotfiles/prompts/code-review.schema.json`.
Результаты складывай в scratchpad-директорию сессии (`$OUT` ниже).

## Шаг 1. Запусти обоих ревьюеров

Codex — через shell в фоне:

```sh
codex exec -s read-only --ephemeral \
  --output-schema ~/dotfiles/prompts/code-review.schema.json \
  -o "$OUT/codex-review.json" - < ~/dotfiles/prompts/code-review.md \
  > "$OUT/codex-review.log" 2>&1
```

Claude — субагент `general-purpose` через Agent. В его задание включи
содержимое `~/dotfiles/prompts/code-review.md` целиком и инструкцию записать
JSON-ответ в `$OUT/claude-review.json`.

## Шаг 2. Дождись обоих ревьюеров

Если один из ревьюеров завершился с ошибкой или не записал файл, покажи хвост
лога и продолжай только с замечаниями второго ревьюера, явно это отметив.

Если оба ревьюера завершились с ошибками или не записали файл, то напиши
об этом и заверши ревью.

## Шаг 3. Объедини результаты

1. Объедини одинаковые замечания из двух источников в одно, оставив
   наибольший severity. Пометь каждый источником: `claude`, `codex` или
   `оба`.
2. Отсортируй по важности: сначала severity, при равном — совпадение у обоих
   ревьюеров выше.

## Шаг 4. Ответ

Напиши общее количество найденных замечаний (`blocker`, `major`, `minor`).

Если замечания есть, покажи не больше трёх, начиная от самого важного,
на русском языке. Каждое замечание состоит из перечисленных ниже элементов,
не более одного элемента на строке:

- Номер замечания в виде эмодзи 1️⃣, 2️⃣ или 3️⃣, затем краткое саммари замечания
  жирным шрифтом, затем в скобках ревьюер и severity — все вместе до 80
  символов. Пример:
  ```
  1️⃣ Сервис падает при ошибке в настройках (codex, major)
  ```
- `file:line`
- Эмодзи "✍️", далее краткое описание недостатка и в какой ситуации
  проявляется.
- Если ревьюеры вернули возможные решения, то каждое решение начинай с
  эмодзи "⚙️", затем номер решение (если более одного решения) и далее
  краткое описание решения (может занимать более одной строки).
  - Пример с одним возможным решением:
    ```
    ⚙️ Значения по умолчанию для настроек.
    ```
  - Пример с двумя возможными решениями:
    ```
    ⚙️ 1. Значения по умолчанию для настроек.
    ⚙️ 2. Писать в лог не исключение, а информацию о некорректных настройках.
    ```
- Если это замечание не последнее, то добавь одну пустую строку, чтобы
  замечания были визуально отделены друг от друга.
