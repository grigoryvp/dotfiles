Проведи ревью изменений в текущей ветке двумя независимыми ревьюерами
параллельно, затем объедини их находки.

Промпт ревью: `~/dotfiles/prompts/code-review.md`.
JSON-схема находок: `~/dotfiles/prompts/code-review.schema.json`.
Результаты складывай в scratchpad-директорию сессии (`$OUT` ниже).

## Шаг 1. Запусти обоих ревьюеров

Codex — через shell в фоне:

```sh
codex exec -s read-only --ephemeral \
  --output-schema ~/dotfiles/prompts/code-review.schema.json \
  -o "$OUT/codex-review.json" - < ~/dotfiles/prompts/code-review.md \
  > "$OUT/codex-review.log" 2>&1
```

Claude — субагент `general-purpose` через Agent. В его задание включи
содержимое `~/dotfiles/prompts/code-review.md` целиком и попроси записать
JSON-ответ в `$OUT/claude-review.json`.

## Шаг 2. Дождись обоих ревьюеров

Если codex или claude завершились с ошибкой или не записали файл, покажи хвост
их лога и продолжай только с находками второго ревьюера, явно это отметив.

## Шаг 3. Объедини результаты

1. Объедини одинаковые находки из двух источников в одну, оставив
   наибольший severity. Пометь каждую источником: `claude`, `codex` или
   `оба`.
2. Отсортируй по важности: сначала severity, при равном — совпадение у обоих
   ревьюеров выше.

## Шаг 4. Ответ

Напиши общее количество найденных замечаний (`blocker`, `major`, `minor`).

Если замечания есть, покажи не больше трёх, начиная от самого важного,
в виде нумерованного списка на русском языке. Для каждого: источник,
`file:line`, в чём недостаток и в какой ситуации проявляется, кратко
очевидные решения (если они есть).
